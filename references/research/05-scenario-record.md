右侧属性面板要保持密度，支持浅/深主题和品牌色。下面是合成片段，只有这个范围，没有运行程序、导入、Theme 文件或 model 定义：

```qml
ColumnLayout {
    Repeater {
        model: propertiesModel
        delegate: Rectangle {
            color: "#ffffff"
            radius: 12
            implicitHeight: 64
            RowLayout {
                Text { text: model.label; color: "#999999" }
                TextField { text: model.value }
                Text { text: model.unit; color: "#999999" }
            }
        }
    }
}
```

### 3. 候选方案与推荐

输入控件核验默认、hover、pressed（控件适用时）、disabled、键盘焦点，以及已定义错误与焦点组合。若 ComboBox 等已有持续选择，保留选择信息与焦点；不把每个属性行自动变成可选按钮。批量混合值如何显示、编辑何时提交、失败如何回退，列为产品决定；本轮不补破折号、空值或写回处理。

目标是让“高级选项”的禁用信息和弹窗动作清楚，并为浅深主题与品牌变化建立可复用方案；仅出设计方案。代码可证：整组 enabled 绑定到未知的 `advancedAvailable`，禁用时整组 opacity 为 0.3；需求明确：三个按钮都拟用品牌色实心。上述事实置信度高，但实际外观、禁用原因、选项模型、保存/即时生效/取消/关闭/重开行为、Qt 次版本及 Controls style 均未知。0.3 是输入现值，不是已验证的可读性标准。

### 3. 候选方案与推荐

- **A，最小改动：**保留分区、按钮集合与业务绑定；将整组透明度方案改为待验证的禁用角色方案，并在确认按钮模型后调整强调。收益是改动集中，代价是较多信息时的布局问题仍未解决。

### 4. 主题/组件映射
